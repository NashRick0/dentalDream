# dentalDream

Sistema de gestión de citas para consultorios dentales.

## ¿Qué hace?
Permite al dentista registrar los datos de sus pacientes, anotar sus problemas
dentales y la zona donde se presentan, y asignarles su cita de forma organizada.

## Estructura
- `documentacion/descripcion.txt`: descripción del proyecto
- `src/index.html`: página principal
